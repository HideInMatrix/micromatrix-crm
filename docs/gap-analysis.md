# 与 CordysCRM 的功能差距分析（历史基线）

> 自 2026-08-17 起，本文件不再作为主要实施路线。项目已经切换为以项目内 `CordysCRM/` 源码为功能基准的语义迁移方式。当前功能状态请看 [cordys-parity.md](./cordys-parity.md)，当前实施顺序请看 [cordys-wave1-remainder-plan.md](./cordys-wave1-remainder-plan.md)。本文件仅保留早期页面探测和人工差异分析结果，供回溯使用。

> 对照基准：CordysCRM 社区版（本地实例 **v1.8.1**；文档历史曾写 v1.7）。
> 状态标记：✅ 已实现 · 🟡 部分实现 · ❌ 未实现 · ⛔ 明确排除（对应 Cordys 付费/企业版能力）

## 四、差距汇总（按优先级）

- **P0**：已落地：附件系统、客户查重、客户 360（P0 Tab）、商机产品明细。商业标讯数据源已取消，不排期
- **P1**：跟进计划（含转记录/到期/我的计划）、合同可配置阶段、商机关闭规则、多公海多线索池+库容、保存的列表视图、客户合并、异步导出中心、默认字段包、客户标签、商机/报价联系人、操作历史、回收站、全局搜索、目标管理、批量操作、线索查重、API Key、看板拖拽、合同到期提醒、打印模板、xlsx 导入新建/更新、登录安全、列表范围 Tab、移动端补商机/合同、审批抄送
- **P2**：表单引擎（分组/联动/LOCATION/关联/子表/图片/公式函数）、发票开票明细、订单阶段与明细收货、价格表、加签/退回/依次审批、条件分支、数据字典、公告、客户层级、脱敏、自定义表单模块、产品分类树、编号规则、消息渠道与模板、SSO/用户同步
- **P3**：国际化
- **暂不排期**：工作流菜单（与审批流并列，本轮未跟接口）；付费能力维持排除；商业标讯数据源（剑鱼/千里马）已取消

实施排期见当前阶段执行计划 [cordys-wave1-remainder-plan.md](./cordys-wave1-remainder-plan.md)。
