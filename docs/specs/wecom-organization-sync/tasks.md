- [x] 7. 实现预览批次、并发控制和查询 API
  - 新增组织同步模块、Controller、DTO、Service 和共享前后端契约。

  - 使用活动批次唯一索引和数据库 advisory lock 处理并发；识别并清理超时遗留的 `FETCHING` 状态。
  - 所有接口校验 `system:dept:sync` 并限定当前租户，跨租户批次统一返回 404。

- [x] 8. 实现冲突解决和批次失效规则
  - 支持部门、成员冲突选择“绑定现有资源”或“跳过”，只保存 resolution，不允许客户端改写快照和动作。
  - 校验绑定目标属于当前租户、资源类型正确且没有被同平台其他外部 ID 占用。
  - 未解决冲突阻止应用；跳过项不得新增、修改或建立映射。
  - 配置凭据版本变化时立即失效待应用批次，前端只能重新生成预览。
  - 为提交解决方案和预览失效写入不含敏感字段的操作日志。
