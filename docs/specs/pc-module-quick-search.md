# PC 端模块快捷搜索：规划与实施说明

## 目标与边界

- 仅面向 **PC 端**线索（含线索池）与客户列表；移动端路由、页面、通知及其它模块不改动。
- 将“搜索什么”交给拥有模块设置权限的管理员，普通用户只看预设的“字段、查询、重置”区域。
- **保留**高级筛选 `AdvancedFilter.vue`、保存视图 `SavedViewBar.vue` 以及数据/API；通过模块配置控制入口显隐。不得删除既有视图数据或撤销后端权限检查。
- 使用现有表单元数据 `ModuleFormProp` 的 `quickSearch` 扩展键存储，不新增表或独立业务设置模块。配置归属当前租户与模块，通过现有 `metadata/:module/form` 读取及 `form-prop` PATCH 保存。

## 配置模型

```ts
interface ModuleQuickSearchConfig {
  enabled: boolean
  showAdvancedFilter: boolean
  showSavedViews: boolean
  items: Array<{
    id: string                         // UI 稳定键
    kind: 'field' | 'preset_select'
    label: string                    // 搜索框标签
    fieldKey?: string                // 输入/字段控件只引用一个字段
    operator?: 'contains' | 'eq' | 'gte' | 'lte'
    placeholder?: string
    options?: Array<{               // 仅 preset_select 下拉框使用
      id: string
      label: string                  // 例如：小学、初中、重点跟进
      searchMode: 'AND' | 'OR'        // 当前选项内部条件关系
      conditions: FilterCondition[] // 每项是现有高级搜索表达式
    }>
  }>
}
```

- 新配置默认是空控件列表，管理员按需要新增文字搜索或下拉框搜索；不提供泛关键词类型，也不兼容早期保存的 `keyword` 配置。
- `field` 输入框只引用一个可筛选字段。普通枚举字段的选项仍来自元数据；一个输入框不能绑定多个条件。
- `preset_select` 是管理员自定义下拉框：每个选项绑定一组高级搜索 `FilterCondition[]`，通过 `searchMode` 决定该选项内部「全部满足 / 任一满足」。用户只选择选项，不编辑表达式；不选选项代表不附加条件。
- **多控件之间为 AND，每个预设下拉选项内部可为 AND 或 OR**。例：`(小学一年级 OR 小学二年级) AND 意向等级=高`。后端按组选取 ID 后与已存在的关键词、字段筛选和视图结果取交集，而不是把 OR 条件平铺；不覆盖后端租户/负责人/部门/线索池限制。查询、分页、导出采用同一套参数。
- 修改字段或删除字段后，失效的搜索项在渲染时忽略，保存时拒绝无效配置。
- 关闭快捷搜索时，清空已提交的快捷条件，退回历史关键词栏；避免出现不可见筛选。
- 没有配置快捷搜索的模块继续显示原列表工具栏；首次保存搜索配置后，根据管理员开关决定隐藏高级筛选及视图入口。

## 交互

1. 模块设置 > 线索 / 客户 > **搜索设置**：控件列表初始为空；新增入口仅保留 **「添加文字搜索」**（绑定单字段）和 **「添加下拉框搜索」**（绑定预设条件组选项）两个按钮。下拉框可增加多个选项，每个选项使用现有高级搜索条件编辑组件配置字段、操作符、固定值及 AND/OR；可上下调整控件顺序。
2. 列表顶部显示自适应横排搜索条（字段名、输入/选择、查询、重置）；未配置时保留既有搜索体验。
3. 查询时才应用草稿输入；重置清空快捷搜索条件并回到第一页。改变线索池/系统视图不越权；旧浏览器中隐藏的保存视图不得继续施加筛选条件。
4. 在搜索设置抽屉中，选项的条件编辑器嵌套于折叠面板，`ElSelect` / `ElDatePicker` 等弹层必须启用 `teleported` 以挂载到顶层容器，避免被折叠面板 `overflow: hidden` 或下一选项内容遮挡。
5. 视图隐藏时仍保留列表“显示列”能力，避免将列设置入口变成空操作；客户“本人/部门/协作”系统数据范围不能因为隐藏视图而被扩大。

## 验收

- 管理员只能通过两个入口新增文字搜索或预设下拉框；旧关键词控件已删除，不保留兼容。线索、客户用户只看到输入框和下拉选项，能查询/重置/翻页/导出一致的筛选结果；不选下拉项时无额外限制。
- 在第一个下拉选项中打开字段/操作符/枚举值下拉菜单，弹层能够正常盖住下方其他选项，不被 `el-collapse` 裁剪。
- 下拉选项的 AND/OR 可组合多个条件，筛选结果需按 `（选项条件组）AND（其他搜索控件）` 计算；未知/删除字段不得产生匹配全表的错误结果；管理员不能借助前端配置突破数据权限。
- 隐藏高级筛选与视图后仍可恢复；站内已有视图及数据不丢失；隐藏时没有“幽灵过滤”。
- PC 线索池、公海等复用路径不被破坏，移动端无文件改动。
